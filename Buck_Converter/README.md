# DC–DC Buck Converter

This project demonstrates the design and implementation of a **DC–DC buck (step-down) converter PCB** for regulated low-voltage power supply applications.

## Files Included
- circuit diagram
- 3D images
- component valu calculation

## Description
The DC–DC buck converter is designed to convert a **variable DC input voltage (up to 40V)** into a **regulated 5V DC output** using the **LM2596 switching regulator IC**.  
The PCB was designed using EasyEDA with proper component placement, power routing, and ground pour to ensure stable voltage regulation and efficient power conversion.

This design is suitable for powering **embedded systems, microcontrollers, and low-voltage electronic circuits** from higher-voltage DC sources.

## Components Used
- LM2596 Buck Converter IC  
- Inductor  
- Schottky Diode  
- Input and Output Capacitors  
- Screw Terminal Connectors
